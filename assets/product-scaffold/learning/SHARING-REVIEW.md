# 可复用经验审查

本目录属于当前产品，保存“哪些本地证据被提炼为共享候选”的私有映射。共享 Skill 只接收脱敏后的通用模式，不接收产品名、文件名、绝对路径、网址、IP、账号、授权字段、客户数据、原始日志或二进制内容。

## 当前状态

- 待提炼候选: `0`
- 已导出候选: `0`
- 已补充共享证据: `0`
- 最近一次审查: `UNVERIFIED`

## 审查规则

1. 先把事实写入 `EVIDENCE-LEDGER.yaml` 和相关分析报告；
2. 只提炼能跨产品复用的识别、操作、验证、失败和回滚方法；
3. 运行共享 Skill 的自动脱敏检查；
4. 候选经验不直接用于真实产品操作；
5. 满足独立证据门槛并完成审核后，才晋升为共享模式。
